# 2026-10-26 — Native animated appearance trial

The owner accepted prepared catalogue colours and approved a provisional visual
trial through the MSC executable. They want continuous horizon-dependent
brightness/colour flickering, variable light footprints and unequal tapered rays.
Time pause preserves animation; picture mode freezes it. Appearance approval
remains provisional until native visual review.

The agent implemented an opt-in native trial with live controls, linear light
accumulation and a separate final display conversion. The ordinary viewer,
catalogue and strict TOML schema remain unchanged. Zone selection and compact/full
profiles are design direction awaiting measurements, not implemented scaling.
