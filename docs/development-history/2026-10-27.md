# 2026-10-27

The owner likes the sky appearance but reports imperceptible animation and
pixelation. They requested removal of the appearance-tuning CLI options and
keyboard shortcuts added during the native trial.
The [trial](../decisions/stellar-appearance-trial.md) retains activation and
picture freeze/resume with its existing model defaults; visual acceptance remains
open. JSON-based customization is an owner-suggested
[possible later task](../todo.md#later-customization), not an implementation decision.

The owner subsequently approved a replacement informed by scintillation research,
starting with removal of unused experiment plumbing. The revised
[native trial](../decisions/stellar-appearance-trial.md) uses frame-averaged
frequency components and related RGB signals with the quieter profile. Visual
acceptance remains open; optimization for million-source animation is explicitly
[after appearance review](../todo.md#animation-validation-and-scaling).
