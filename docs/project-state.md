# Current project state

Last updated: 2026-09-12.

This is the short hand-off record for continuing MSC work from another account
or session. Detailed decisions remain in the linked focused documents.

## Implemented and verified

- M1 has an end-to-end 4,096-row Gaia path from CSV-gzip parsing through the
  typed catalogue, binary round trip, fixed Toulouse transformation, zenith
  projection, and GLFW/OpenGL rendering.
- The current automated suite contains 96 discovered tests and passed at the
  last recorded verification.
- The display uses fixed-size grayscale points with a minimal relative Gaia G
  brightness cue. Colour, calibrated exposure, scintillation, and proper-motion
  propagation are not implemented.
- A separate Hipparcos-2 acquisition produced 42 provisional bright-source rows
  and preserved official Gaia cross-match evidence.

## Approved, not yet implemented

- Keep Gaia and Hipparcos source data and parsers separate, then normalize both

- Preserve separate measurement, calculated-state, and visual-state boundaries.
- Replace the vendored generated GLAD directory with pinned GLAD 2.0.8 fetched
  and generated by CMake. External libraries and a future package manager such
  as Conan are acceptable; no package-manager migration is selected.
- Apply the repository cleanup described below without changing runtime

## Acquisition status

The latest verified Gaia checkpoint contains 76,048,576 complete, unique,
brightness-ordered records. The target remains 134,217,728 records subject to
the 10,000,000,000-byte compressed-file limit. A final catalogue does not exist
until acquisition verification creates `manifest.json`.

On 2026-09-12 the transient `msc-gaia-acquisition-retry.service` was active at
restart count 57. Each recent attempt spent about four minutes trying to submit
batch 26, received HTTP 500, failed, waited one minute, and restarted. The last
completed server job had exceeded ESA's 7,200-second execution limit. The loop
was alive but had made no catalogue progress: the checkpoint remained at
76,048,576 rows. Its batch sizing, endpoint, or query partitioning needs a
separate decision before changing the acquisition tool. The failing transient service was then stopped safely; the checkpoint remains resumable.
